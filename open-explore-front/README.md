# open-explore

## Getting Started

### Clone the Repository
```bash
cd open-explore
```

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run serve
```

### Build for Production
```bash
npm run build
```

## Backend Repository

Backend project repository: os-explore-console
